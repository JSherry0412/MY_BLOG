# Sherry's Blog

一个本地调试中的个人博客：包含首页、文章、动态、项目收藏、关于页和博客贡献图。头像、签名、页面文案与内容可在浏览器中编辑。

首页采用最终确定的布局：全屏封面、个人介绍与角色展示、近期文章，以及下方的博客贡献图。封面文字、署名和壁纸可在首页“编辑此页”中修改；壁纸最多 3 MB，留空使用示例壁纸。鼠标在封面向下滚动时会进入首页内容，之后保持普通滚动。

## 启动与编辑

安装 Node.js 后，双击 `打开博客编辑器.bat`，等待浏览器打开博客；也可以在项目目录执行 `node editor-server.cjs`，然后访问 <http://127.0.0.1:4173/>。保持命令行窗口打开，关闭它会停止本地网站。

进入首页、文章、动态、项目、关于等页面，点击右上角“编辑此页”打开对应的编辑面板；在文章详情页点击会定位到该文章。修改后点保存，再关闭面板，即可看到结果。首页可以上传头像（PNG、JPG、WebP、GIF，最大 1 MB）、填写名称、签名、标签以及首页标题和介绍。

独立管理页面也可直接打开 <http://127.0.0.1:4173/editor>。编辑器只监听本机，不是互联网服务；使用普通静态服务器无法保存内容。

## 数据与 GitHub

个人资料、文章、动态、项目、关于页设置和贡献记录保存在本机 `blog-data.js` 中。这个文件已加入 `.gitignore`，不会随框架更新提交到 GitHub；请自行备份。新环境首次启动会从空白 `blog-data.example.js` 创建该文件。`config.js` 中的内容是首次使用时的示例和默认值，编辑器中的内容以 `blog-data.js` 为准。不要在源代码或数据里保存密码、令牌。

看板娘原图和用于隐去白底的蒙版分别位于本机 `personal/character.png` 和 `personal/character-mask.png`；`personal/` 不会提交到 GitHub。蒙版是为当前角色制作的，如果之后更换角色，请先移除旧蒙版，避免它遮挡新图片；更换后可以使用本身带透明背景的 PNG。新环境未提供角色时会隐藏图片位置，不影响文章阅读。`assets/wallpaper.png` 是随框架提供的示例壁纸，不包含个人数据。

贡献图只统计通过编辑器新建或实际修改文章和动态的次数；资料、页面设置、项目、访问和重复保存不计入。日期采用本机日期。直接修改文件不会自动计入。

博客目前没有公开部署。未来需要在线编辑时，需另行配置服务器、持久化存储与管理员身份验证，再决定如何备份或上传个人数据。

## 框架开发

`app.js` 和 `style.css` 管理前台页面；`editor.html`、`editor.js`、`editor.css` 和 `editor-server.cjs` 负责本地编辑。文章支持基础 Markdown（标题、段落、引用、列表、代码和链接等）。框架变更可以提交至 GitHub，提交前使用 `git status` 确认不包含个人数据。
