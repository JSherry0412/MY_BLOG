# Sherry's Blog

一个可继续定制的个人博客。包含首页、文章搜索和分类标签筛选、文章阅读、生活动态、项目收藏和关于页面，采用响应式毛玻璃风格。

## 本地预览

在项目目录打开终端，运行：

```powershell
python -m http.server 8000
```

浏览器访问 <http://localhost:8000>。文章通过 HTTP 加载，请不要直接双击 HTML 文件预览。也可使用任何静态文件服务器。

## 修改内容

### 个人资料与博客编辑器

双击 `打开博客编辑器.bat`，或在项目目录运行 `node editor-server.cjs`，然后打开 <http://127.0.0.1:4173/editor>。编辑器仅监听本机，关闭命令行窗口即停止。首页可以在 <http://127.0.0.1:4173/> 预览。Node.js 是运行本地编辑器的唯一依赖。

个人资料的头像、显示名称、签名和标签默认留空，与 GitHub 资料无关。图片保存在博客数据文件里，支持 PNG、JPG、WebP、GIF，最大 1 MB。保存后刷新首页即可看到变化。编辑器中的文章和动态保存到 `blog-data.js`：首次编辑会接管原 `config.js` 的文章或动态列表；其他页面配置仍在 `config.js` 中。

首页贡献图只记录在编辑器中实际新建或修改文章、动态的次数；不变的重复保存、修改个人资料、访问页面和普通代码提交都不计入。日期采用本机本地日期。历史示例不会自动计入，直接修改文件的内容也不会自动计入。数据是静态博客文件的一部分，不依赖 GitHub 贡献数据。编辑器保存只更新本机文件，需要提交并推送仓库才能同步到 GitHub；如已配置网站部署，还需等待部署更新。

- 编辑 `config.js` 修改昵称、简介、GitHub 地址、兴趣、经历、动态、项目和文章列表。动态按数组顺序展示；项目的 `url` 留空时不会生成链接。
- 在 `posts/` 中添加 Markdown 文件，再在 `config.js` 的 `posts` 数组中添加对应条目。
- 文章可设置 `category` 和 `tags`（字符串数组）。搜索范围为标题、分类、标签和摘要，不搜索文章正文；文章列表和上一篇／下一篇按配置数组的顺序排列。
- Markdown 支持一级至三级标题、段落、引用、粗体、斜体、删除线、行内代码、代码块、简单有序／无序列表、分隔线以及 HTTP(S) 或邮件链接；其他复杂语法暂不支持。文章目录根据二、三级标题生成。
- 编辑 `style.css` 调整颜色、布局与样式；编辑 `app.js` 调整页面结构和交互。
- 示例文章和简介是占位内容，可按自己的想法替换。
- 文章页留言区域和 `config.js` 中的 `music` / `comments` 是未来接入服务的预留项，当前没有实际播放器或留言服务，修改 `enabled` 不会启用功能。不要在前端文件中填写任何密钥。

## 同步到 GitHub

完成修改后，在项目目录运行 `git status` 检查变更，再执行 `git add`、`git commit` 和 `git push`。请不要提交密码、令牌或私人资料。仓库推送成功不等于网站已经公开部署；部署方式可在后续确定。
